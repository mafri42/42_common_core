MYPY:
Mypy è un verificatore statico dei tipi (“static type checker”) per il linguaggio Python.
Fornisce tipizzazione opzionale e graduale, permettendo di aggiungere annotazioni di tipo (PEP 484) al codice Python 
per individuare errori prima dell’esecuzione. È ampiamente utilizzato per migliorare l’affidabilità e la manutenibilità 
di progetti Python di grandi dimensioni

- Naming conventions (nomi corretti)
    Classi → PascalCase → es: GardenPlant
    Variabili e funzioni → snake_case → es: water_plant
- Type hints obbligatori
    → Devi indicare i tipi usando annotazioni Python
(controllati con mypy)
- Puoi usare .capitalize() sulle stringhe anche se non è tra le funzioni “autorizzate”
- Non serve validare input
    → Non devi controllare errori utente, a meno che non sia richiesto.

🧠 Spiegazione IMPORTANTISSIMA: if __name__ == "__main__"
Dice a Python:
“Esegui questo codice solo se il file è avviato direttamente”

💡 Python usa __name__ per distinguere
Se esegui il file → __name__ = "__main__"
Se lo importi → __name__ = "nome_file"
👉 Se esegui il file → stampa
👉 Se lo importi → non stampa niente


🧠 Cos’è la shebang (#!)
È una riga speciale che si mette all’inizio del file Python:
#!/usr/bin/env python3

🔍 Cosa significa?
Dice al sistema operativo:
“Usa Python per eseguire questo file”
💡 Senza shebang
Devi sempre scrivere:
python3 ft_garden_intro.py
🚀 Con shebang
Puoi eseguire il file direttamente:
./ft_garden_intro.py
👉 come se fosse un programma normale

⚙️ Ma serve un passo in più
Devi rendere il file eseguibile:
chmod +x ft_garden_intro.py

🎯 Perché è importante
✔ rende lo script più professionale
✔ funziona come un vero programma Linux/macOS
✔ spesso richiesto nei progetti (come qui)

🧠 Riassunto veloce
#! = “usa questo programma per eseguire il file”
#!/usr/bin/env python3 = usa Python 3
serve per lanciare lo script con ./file.py


EX1:
🎯 Obiettivo
Gestire più piante usando una classe Plant
👉 Non devi più fare variabili separate

🌱 Cos’è una classe (spiegazione semplice)
Una classe è come uno stampo.
Esempio:
classe = "Plant"
oggetti = Rose, Sunflower, Cactus

🎯 Obiettivo
Creare un programma che:
gestisce più piante
usa una classe Plant
stampa le informazioni in modo organizzato

🧱 Struttura richiesta
1. Classe Plant
Devi creare una classe che rappresenta una pianta:
    class Plant:
2. Attributi (dati della pianta)
Ogni pianta ha:
    name → nome
    height → altezza in cm
    age → età in giorni
Questi vengono inizializzati con:
    def __init__(self, name: str, height: int, age: int) -> None:
👉 Questo metodo si chiama costruttore
3. Metodo show()
Serve per stampare i dati della pianta:
    def show(self) -> None:
Output:
    Rose: 25cm, 30 days old
4. Creazione degli oggetti
Devi creare almeno 3 piante:
    rose = Plant("Rose", 25, 30)
    sunflower = Plant("Sunflower", 80, 45)
    cactus = Plant("Cactus", 15, 120)
5. Stampa
    rose.show()
    sunflower.show()
    cactus.show()

🔥 Concetti IMPORTANTI

🧠 1. Classi (OOP)
La classe è un modello
Gli oggetti sono istanze della classe
👉 Plant = modello
👉 rose = oggetto concreto

🧠 2. __init__
È il costruttore
Viene chiamato quando crei un oggetto
rose = Plant("Rose", 25, 30)

🧠 3. self
Rappresenta l’oggetto corrente
Permette di accedere ai dati della pianta
self.name

🧠 4. Metodo vs costruttore
__init__ → inizializza i dati
show() → esegue azioni (stampa)

🧠 5. Naming conventions
Classi → PascalCase → Plant
Variabili → snake_case → rose, sunflower

🧠 6. if __name__ == "__main__"
Serve per eseguire il codice solo quando il file è lanciato direttamente
evitare esecuzioni quando il file viene importato

🧠 7. Struttura consigliata
class Plant:
    ...

if __name__ == "__main__":
    ...

🎯 Riassunto finale
✔ Crei una classe Plant
✔ Usi __init__ per inizializzare i dati
✔ Usi self per accedere agli attributi
✔ Crei più oggetti
✔ Usi show() per stampare
✔ Rispetti naming conventions
✔ Usi if __name__ == "__main__"

Simulare la crescita di una pianta nel tempo (una settimana) usando una classe Plant 
in stile OOP.

Dentro una classe, il metodo che inizializza gli attributi si chiama:
__init__
E deve avere sempre:
self
come primo parametro.

1. self
Serve per riferirsi all’oggetto stesso.
È quello che ti permette di fare:
    self.name
    self.height
    self.age

2. Il costruttore
Deve:
ricevere i parametri (name, height, age)
salvarli dentro l’oggetto

3. Il nome del metodo
ft_plant_growth non deve stare dentro la classe come costruttore.
Quel nome è il nome del file, non del metodo.
